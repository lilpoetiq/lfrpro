# Employee Access Guide - LFR Dashboard

## Quick Access

Once DNS is set up by your IT/admin, access the dashboard at:

**http://lfrpro.com:3000**

## Login Credentials

- **Username:** `admin`
- **Password:** `ZeroEcho30`

## If DNS is Not Set Up Yet

You can access the dashboard directly via IP address:

**http://10.0.0.15:3000**

## Troubleshooting

### Can't access the site:

1. **Make sure you're on the company network/WiFi**
2. **Try the IP address directly:** `http://10.0.0.15:3000`
3. **Clear your browser cache**
4. **Try a different browser**

### DNS not working:

If `lfrpro.com` doesn't resolve, contact IT to set up local DNS, or use the IP address directly.

## Supported Browsers

- Chrome (recommended)
- Firefox
- Safari
- Edge

## System Requirements

- Any modern web browser
- Internet connection (for initial load)
- Must be on the same network as the server
